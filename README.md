# 🎯 Why BigDecimal?
Instead of using `float` or `double` for important calculations, this project uses `BigDecimal` to avoid floating-point precision errors.

Example:
```java
0.1 + 0.2 != 0.3
```

Using `BigDecimal` ensures accurate and reliable calculations. ✅
